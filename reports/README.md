# R Data Analysis Portfolio

## About This Repository
This repository contains my projects as I learn R programming,
statistics, and data analysis.

## Project 1: First R Analysis
**File:** `first-r-analysis.R`

## Project 2: Sales Summary
**File:** `sales-summary.R`

Analyzes seven days of sales data and calculates:
- Total sales
- Average sales
- Highest sales
- Lowest sales
